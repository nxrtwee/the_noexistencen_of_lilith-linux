# Third-party boundaries

The original game, its executable files, IL2CPP metadata, characters, audio, fonts and artwork belong to their respective rights holders. None are included in this repository or its allowlisted release archives. The game title is used solely to identify compatibility. No affiliation or endorsement is claimed.

The bridge's original project code is licensed under MIT. It uses public/system interfaces and dynamically links Qt 6, KDE LayerShellQt/KIdleTime, X11/Xext and their transitive runtime dependencies. The proxy is built with Wine development headers/import libraries and loads the runtime's version library. Compilers, CMake, Python, Wine/Proton and dependencies retain their own licenses.

No third-party libraries or game resources are vendored in the prepared archives. Do not bundle system libraries or a Wine/Proton runtime without separately reviewing their distribution and license obligations. A binary distributor must review the applicable Qt/KDE licenses, notices and relinking requirements for the exact dependency versions shipped. Dynamically linking and not bundling libraries does not eliminate all possible obligations.

The small machine-code signatures in the compatibility checks identify the supported executable prologues; the game binary itself is not shipped. Verify applicable game terms and local law before public distribution. This file is a scope/provenance statement, not a legal opinion or a license grant for third-party materials.
