# Changelog

## 0.1.0-alpha.1 — release candidate

First public-release candidate, not yet published.

- Native KDE Wayland presenter with original game visuals and input.
- Portal hotkeys, folder picker, local/URI opening and Unicode/Linux path presentation.
- Native tray/menu/actions, notification and note badge.
- XDG startup setting, active-app/fullscreen/idle integration.
- Targeted local-file clipboard and drag/drop.
- MPRIS player discovery/control; hide empty local panel for external playback; idempotent targeted Stop/Pause.
- Recovery of portal sessions and the bridge-owned KWin observer; screen lifecycle handling.
- Per-user installer/configuration, backup/restore, game-build hash checks and Steam-library discovery.
- Portable CMake native build, isolated regression tests, source/binary allowlist packaging and checksums.

Known limitations: see docs/COMPATIBILITY.md. MIT licensing was approved by the owner; binary-release installation smoke testing remains required.
