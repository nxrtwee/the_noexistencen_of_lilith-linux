# Lilith Linux Bridge

Неофициальный Linux-мост для **The NOexistenceN of Lilith** — настольного помощника, **не визуальной новеллы**.

[English](README.md) · [Установка](docs/INSTALLATION.md) · [Совместимость](docs/COMPATIBILITY.md) · [Сборка](docs/BUILDING.md)

**Экспериментальная альфа: KDE Plasma Wayland, Linux x86_64.** Это не самостоятельная копия игры и не официальный Linux-релиз. Нужна собственная установленная Steam-версия, App ID `4643090`. Файлов игры в репозитории нет.

## Возможности

Игра продолжает работать через Proton, а нативный Qt/LayerShellQt-мост выводит исходный интерфейс поверх окон и заменяет системные интеграции Wine:

- оверлей и ввод, взаимодействие с окнами KWin;
- сохранённые глобальные хоткеи через портал, включая физические позиции RU/EN;
- выбор папок, открытие файлов и ссылок средствами рабочего стола;
- корректные Unicode-пути и Linux-представление путей;
- нативный трей, исходные действия меню, уведомления и значок заметок;
- добровольно включаемый автозапуск, активное приложение, fullscreen и простой;
- файловый буфер обмена и перетаскивание на персонажа;
- внешние плееры через MPRIS: пустой внутренний плеер скрыт, остановка отправляет паузу управляемому плееру;
- переподключение к порталу и собственному наблюдателю KWin без перезапуска оболочки.

Интерфейс игры, шрифты и графические ресурсы не заменяются. GNOME устанавливать не нужно.

## Установка

Требуются KDE Wayland, запущенный Steam, уже созданный игрой Proton-префикс, Python 3.11+ и нативные зависимости из [инструкции](docs/INSTALLATION.md). Проверен DWProton 11.0-16; другие версии не гарантируются. Первый бинарный кандидат собран на Arch-подобной системе и не универсален для всех дистрибутивов.

Размести мост в постоянной доступной для записи папке и закрой Lilith. Без `sudo`:

```sh
python3 install.py --dry-run --proton /путь/к/proton
python3 install.py --proton /путь/к/proton
./launch.sh start
```

Если скачаны только исходники, перед установкой:

```sh
./build.sh
./build-host.sh
ctest --test-dir build/cmake --output-on-failure
```

Steam-библиотеки определяются автоматически; пути можно указать вручную. Настроенный в Steam Proton определяется при однозначном совпадении. Игровая сборка проверяется по хешу. Неизвестная сборка без явного согласия не устанавливается.

Установщик копирует только нашу `version.dll` и регистрирует приложение в меню. Чужую существующую DLL/ярлык без `--replace-existing` не заменяет; при разрешённой замене создаёт резервную копию. Автозапуск сам не включает.

**Запускать нужно через пункт «Lilith Linux Bridge» или `./launch.sh start`, при запущенном Steam. Одна замена DLL не запускает нативный мост при обычном нажатии «Играть» в Steam.** Интеграция с параметрами запуска Steam в этой альфе не заявлена.

```sh
./launch.sh status
./launch.sh stop
python3 install.py --uninstall --dry-run
python3 install.py --uninstall
```

Удаление восстанавливает резервные копии и не трогает сохранения/Proton-префикс. Если установленные файлы изменены после установки, удаление останавливается, а не перезаписывает их. Перемещать папку моста после установки нельзя без переустановки ярлыка. Оригинал и мост одновременно не запускай.

## Честные ограничения

- Файловый Ctrl+V — после фокуса на персонаже, без глобального перехвата вставки.
- Простой клавиатуры отдельно не измеряется: используется общая активность системы.
- При внешнем воспроизведении панель Лилит скрыта; название/прогресс внешнего трека не импортируются.
- Изменённая порталом комбинация может не обновляться в интерфейсе настроек игры.
- Сон, блокировка, горячее подключение мониторов, смешанный DPI и многочасовая стабильность ещё требуют ручной проверки.
- GNOME, X11, Flatpak Steam и прочие окружения не проверены. Неизвестные обновления игры могут ломать совместимость.

Рабочая конфигурация: CachyOS, KDE Plasma Wayland, один экран 1920×1080 при масштабе 1, Qt 6.12. [Подробности совместимости](docs/COMPATIBILITY.md).
